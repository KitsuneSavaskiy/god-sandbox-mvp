# Art prompts

このディレクトリは、GodSandbox のアート生成や画像差分検討に使ったプロンプトを保存する場所です。

## 保存するもの

- キャラクター立ち絵のプロンプト
- 表情差分のプロンプト
- 背景、季節、時間帯、UI装飾のプロンプト
- 生成方針や差分意図の短いメモ

## 保存しないもの

- POや実在個人の画像、個人設定、個人情報
- ローカルPCの絶対パス
- secret、API key、token、認証情報
- 外部サービスのprivate URL
- PBI scope外の生成画像そのもの

## 書き方

- ファイル名は対象PBIや用途が分かる名前にする。
- 例: `pbi-world-season-time-backgrounds-001.md`
- 画像ファイルを追加する場合は、そのPBIで許可された `public/**` や `sample/**` の範囲に置く。
- プロンプト本文には、実在個人をモデルにした指定や、PO本人を作中キャラクター化する指定を書かない。

詳細なゲーム方針は `docs/game-plan.md` を参照する。
