# 平面立ち絵キャラを外部ゲームで動かす初心者向けガイド

この資料は、Character Passport のキャラクターを、別のゲームで動かしてみたい人向けのガイドです。

技術者向けの細かい仕様書ではありません。
初めて見る人が「画像が1枚でも、自分のキャラをゲームの中で動かせそう」と分かることを目指します。

## まず知ってほしいこと

Character Passport は、キャラクターを別のゲームへ連れて行くための紹介カードです。

このカードには、名前、画像、紹介文、タグなどが入っています。

別のゲーム側は、必要な情報だけ使えば大丈夫です。
全部の項目を使う必要はありません。

戦闘で使うHPや攻撃力は、別のゲーム側で自由に決めてよいです。
つまり、GodSandboxのルールをそのまま再現しなくてもかまいません。

## 平面キャラとは

平面キャラとは、紙のような1枚絵のキャラクターです。

たとえば、立ち絵、顔画像、カードの絵のようなものです。
最初は1枚だけでもかまいません。

大量の画像差分がなくても、外部ゲームの中で「動いている感じ」を試せます。

## 立体風の世界で平面キャラを動かすとは

立体風の世界とは、奥行きがあるように見えるゲーム画面です。

キャラクター自身は2Dの画像でも、少し動かすだけで、立体風の世界を歩いているように見せられます。

たとえば、次のような見せ方です。

- マス目を少し斜めに見せる
- キャラを紙人形のように立てて見せる
- 移動中に少し上下へ揺らす
- 攻撃中に少し前へ出す
- ダメージを受けた時に少し後ろへ下げる

大切なのは、最初から本格的な3Dを作ろうとしないことです。
まずは「別ゲームの中でキャラクターが動いた」と分かれば十分です。

## Character Passport の画像をどう使うか

Passport に画像の情報がある場合、外部ゲームはそれをキャラクターの見た目として使えます。

例:

```json
{
  "displayName": "Ryo",
  "portraitImage": "/art/portraits/ryo/ryo_normal.jpeg",
  "summary": "森の村で暮らす、まじめで少し不器用な若者。",
  "tags": ["まじめ", "村人", "成長中"]
}
```

この中で、最初に使う情報は少なくてよいです。

- `displayName`: キャラの名前
- `portraitImage`: 表示する画像
- `summary`: キャラの短い紹介文
- `tags`: キャラの雰囲気を表す言葉

外部ゲーム側は、これだけ読めれば小さな表示を作れます。
GodSandboxの内部ルールを全部知る必要はありません。

## 画像が1枚でも試せる

最初から大量の差分画像は不要です。

画像が1枚だけでも、表示位置や大きさを少し変えるだけで動きを出せます。

例:

- 通常: そのまま表示する
- 移動: 少し上下に揺らす
- 攻撃: 少し前に出す
- ダメージ: 少し後ろに下げる、または短く点滅させる

このように、画像が1枚だけでも、外部ゲームの中で動いている感じを試せます。

## 差分画像があると表現が増える

差分画像がある場合は、動きごとに別の絵を使えます。

例:

```text
idle   : 普通の立ち絵
move   : 歩いている感じ
attack : 攻撃している感じ
damage : のけぞる感じ
```

ただし、初期版では必須にしません。

専用画像がなくても、CSSや表示位置の変化だけで最小確認できます。
あとから差分画像を増やせば、表現を少しずつ豊かにできます。

## idle / move / attack / damage の考え方

キャラの見た目を、まず4つに分けます。

`idle` は、何もしていない時の見た目です。

`move` は、移動している時の見た目です。

`attack` は、攻撃している時の見た目です。

`damage` は、ダメージを受けた時の見た目です。

最初は、専用の画像がなくても大丈夫です。

- `idle`: そのまま表示する
- `move`: 少し上下に揺らす
- `attack`: 少し前に出す
- `damage`: 少し後ろに下げたり、短く点滅させたりする

これだけでも、プレイヤーには「今キャラが何をしているか」が伝わります。

## Passportは戦闘ルールを決めない

Character Passport は、キャラの紹介カードです。
戦闘ルールそのものではありません。

外部ゲーム側が自由に決めてよいものがあります。

- HP
- 攻撃力
- 射程
- 移動力
- 仲間か敵か
- 村人かカードかユニットか
- どんな世界で使うか
- どんな役割にするか

たとえば、同じPassportのキャラでも、あるゲームでは仲間として使えます。
別のゲームでは、村人、敵、カード、図鑑の項目として使ってもかまいません。

Passportは「このキャラはこういう人です」と伝える紹介カードです。
「このキャラのHPは必ず10です」と決めるものではありません。

## 外部ゲーム側は必要な情報だけ使えばよい

Passportのうち、まず使うのは次だけで十分です。

- 名前
- 画像
- 紹介文
- タグ

次のような内部情報を、外部ゲーム側が必ず読む必要はありません。

- Faith
- Growth
- Chaos
- tick
- UI state
- live context
- 内部domain model

必要になったら読む。
必要なければ使わない。

このくらいの気持ちで始めて大丈夫です。

## 最初の小さな作り方

最初は、次の順番で試すと分かりやすいです。

1. Passportから名前を読む。
2. Passportから画像を読む。
3. 画面にキャラを表示する。
4. ボタンやクリックでキャラを少し動かす。
5. 攻撃中は少し前に出す。
6. ダメージ中は少し下げる、または点滅させる。
7. HPや攻撃力は、そのゲーム側で仮に決める。

これだけで、「キャラクターを別ゲームへ連れて行く」最初の体験になります。

## よくある不安

### 画像が1枚しかありません

問題ありません。
1枚の画像を上下に揺らすだけでも、移動している感じは出せます。

### GodSandboxの内部ルールを知らないと使えませんか

全部を知る必要はありません。

外部ゲーム側は、まず名前、画像、紹介文、タグだけ読めれば始められます。

### 戦闘ステータスがPassportにありません

それで大丈夫です。

HP、攻撃力、射程、移動力は、外部ゲーム側で自由に決めてよいです。

### 3Dモデルが必要ですか

最初は必要ありません。

2Dの立ち絵を、奥行きがあるように見える盤面へ置くだけでも、十分に試せます。
