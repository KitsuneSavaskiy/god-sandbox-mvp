# World Context

このフォルダは GodSandbox の外部補助ワークスペースです。

## プレイヤー

プレイヤーは新米神様です。

## 世界

小さな箱庭世界です。
キャラクターは自分なりに暮らし、出来事に出会い、変化していきます。

## 基本ループ

1. 箱庭を見る
2. キャラクターに気づく
3. 見守る / 助ける / 試練を与える
4. キャラクターが変化する
5. 必要なら外部へ Character Passport や soul file として持ち出す

## このワークスペースの目的

このワークスペースは、ゲーム外でキャラクターや世界設定を整理するための補助場所です。
GodSandbox本体のコードやセーブ機能を直接置き換えるものではありません。
