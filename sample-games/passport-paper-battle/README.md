# Passport Paper Battle

このサンプルは、Character Passport のキャラクターを、別ゲーム側の1ユニットとして動かす小さな1対1対戦ゲームです。

完成した本番ゲームではありません。
GodSandboxで育てたキャラクターが、外のゲームで「表示され、移動し、攻撃し、被弾する」ことを見るための実験です。

## このサンプルでできること

- 自キャラ1体と敵キャラ1体を表示する
- 横10マス、縦5マスの盤面で遊ぶ
- 左5マスを自陣、右5マスを敵陣として扱う
- 自キャラを上下左右1マス移動する
- 同じ行で攻撃射程内の敵を攻撃する
- 敵が攻撃、または近づく
- 勝利、敗北を確認する
- 使徒の案内を読みながら、Character Passport とこの世界のルールの違いを確認する
- JSONを直接編集せず、画面からHP、攻撃力、射程などの世界ルールを変える
- 定義済みの法則カードを追加し、違う世界としてバトルを作り直す

## 動かし方

repo root でローカルサーバーを起動します。

```bash
python -m http.server 8080
```

ブラウザで次を開きます。

```text
http://localhost:8080/sample-games/passport-paper-battle/
```

`file://` で直接開くと、ブラウザの制限で `sample-passport.json` を読めないことがあります。
その場合でも、同じ内容の予備データで画面は起動します。
サンプル内では、`/art/...` の画像参照を repo root の `public/art/...` から読めるようにしています。

## 使徒の案内

画面の上には「使徒の案内」があります。

ここでは、新米神様に向けて、次の関係を説明しています。

- GitHubに置かれたソースは、この小さな世界の「法律の本」
- `index.html` は画面の骨組み
- `main.js` はキャラがどう動くか、HPがどう減るかを決める法律
- `style.css` は見た目を決める法律
- Character Passport JSON は、GodSandboxから別世界へ渡すキャラクター紹介状

Passportは、キャラの全部を固定する命令書ではありません。
このサンプル世界は、Passportから名前、画像、紹介文、タグを読みます。
HPや攻撃力は、このサンプル世界側の法律として決めています。

## 操作

1. 「キャラを選ぶ」を押す、または盤面上の自キャラを選ぶ。
2. 光っている自陣マスを選ぶと移動する。
3. 同じ行で攻撃射程内の敵を選ぶと攻撃する。
4. 自キャラの行動後、敵が簡単な行動をする。
5. 敵HPを0にすると勝利。自キャラHPが0になると敗北。

## スマホで見る場合

この対応は Mobile Web readiness の初期対応です。
iOS / Android のnativeアプリ化ではありません。

スマホでは、チュートリアルや世界の法則を読んだあとに「バトル盤面へ進む」または「この設定で盤面を見る」を押すと、盤面付近へ移動できます。

盤面は横10マスあります。
画面が狭いスマホでは、盤面を横にスクロールして左の自陣から右の敵陣まで確認してください。
タップするマスやボタンは小さくなりすぎないようにしていますが、本格的なスマホ専用UIは後続PBIで扱います。

Character Passport を持ってくるときは、スマホではファイルを探すより、GodSandbox本体の「キャラ情報をコピー」からこの画面の「JSONを貼り付ける」へ貼るほうが簡単です。
貼り付けたあとに「貼り付けたJSONを読み込む」を押すと、名前、画像、紹介文、タグをこのサンプルへ渡せます。
ファイル選択の導線も残してあるので、PCでは今まで通り `.json` ファイルを選んでも構いません。

iOS / Android のネイティブアプリ対応（Capacitor等）は後続PBIで扱います。

## 世界の法則を調整する

画面の「世界の法則を調整する」では、JSONを直接編集せずに、このサンプル世界のルールを変えられます。

変更できるもの:

- 自キャラHP
- 敵HP
- 自キャラ攻撃力
- 敵攻撃力
- 攻撃射程

数値を変えただけでは、戦闘中のHPを途中で壊さないようにしています。
変更を反映するには、「この法則で世界を作り直す」を押してください。

このボタンを押すと、現在読み込んでいるCharacter Passportはそのまま使い、HPや攻撃力などの世界ルールだけを反映してバトルをリセットします。

## 法則カード

法則カードは、このサンプル世界に用意された定義済みルールです。

例:

- やさしい世界: この世界では主人公が少し倒れにくくなる
- 厳しい世界: この世界では敵の一撃が少し重くなる
- 遠くまで届く声: この世界では少し遠くの相手にも攻撃が届く
- 守りの加護: この世界では主人公が受けるダメージを少し減らす

法則カードは、Character Passport core の新しいパラメータではありません。
あくまで、このサンプルゲーム側が持っている世界ルールです。

未知のパラメータを自由入力で増やす仕組みではありません。
非技術者でも安全に試せるように、決められたカードだけを追加できます。

## キャラ情報JSONを読み込む

画面左では、次のどちらでも Character Passport JSON を読み込めます。

- 「JSONを貼り付ける」に GodSandbox の「キャラ情報をコピー」で取った内容を貼り付ける
- 「キャラ情報JSONを選ぶ」から、GodSandboxで保存したJSONファイルを選ぶ

読み込みに成功すると、次の表示が選んだキャラに変わります。

- 名前
- 画像
- 紹介文
- タグ

何も読み込まなくても、今まで通り固定サンプルのRyoで遊べます。

このサンプルでは、Passportの全部の項目を使う必要はありません。
まず使うのは、`displayName`、`portraitImage`、`summary`、`tags` だけです。

貼り付けたJSONや選んだJSONが読めない場合は、画面にやさしいエラー文が出ます。
その場合でも画面は壊れず、今のキャラのまま遊べます。

確認すること:

- `.json` ファイルを選んでいるか
- `displayName` が入っているか
- `portraitImage` が画像の場所を指しているか
- `tags` が文字の配列になっているか

`portraitImage` が空の場合は、画像の代わりに名前の頭文字を表示します。
古いサンプルのように `displayName` ではなく `name` だけが入っているJSONでも、名前として読める場合があります。

## Character Passport のうち使っているもの

このサンプルの `sample-passport.json` は、次のような紹介カードです。

```json
{
  "schemaVersion": "1.0",
  "characterId": "ryo-sample-001",
  "displayName": "Ryo",
  "summary": "森の村で暮らす、まじめで少し不器用な若者。",
  "portraitImage": "/art/portraits/ryo/ryo_normal.jpeg",
  "tags": ["まじめ", "村人", "成長中"]
}
```

このサンプルが読むもの:

- `displayName`
- `portraitImage`
- `summary`
- `tags`

使わなくてよいもの:

- GodSandbox内部状態
- Faith / Growth / Chaos の生値
- tick
- UI state
- live context
- 内部domain model
- 戦闘用ステータス

## 戦闘値について

PassportにHPや攻撃力を必須にしません。

このサンプルでは、戦闘用の値をゲーム側で仮に決めています。

- HP: 画面の「世界の法則を調整する」で決める
- 攻撃力: 画面の「世界の法則を調整する」で決める
- 移動: 1ターンに上下左右1マス
- 射程: 画面の「世界の法則を調整する」で決める

つまり、GodSandboxの内部ルールを知らなくても、このサンプルゲームはPassportを読めます。

同じPassportのキャラでも、やさしい世界では倒れにくく、厳しい世界では苦戦しやすくできます。
これはPassportを書き換えたのではなく、外部ゲーム側の世界ルールを変えたという意味です。

## 見た目について

キャラは2Dの平面立ち絵として表示します。
盤面は、少し奥行きがあるように見えるマス目にしています。

最小アニメーション:

- idle: 通常
- move: 少し上下に揺れる
- attack: 少し前に出る
- damage: 少し下がって点滅する

画像差分が足りない部分は、CSSの動きで表現しています。
