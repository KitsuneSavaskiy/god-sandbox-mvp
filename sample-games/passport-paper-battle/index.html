Character Passport sample game

Passport Paper Battle

GodSandbox から持ち出したキャラを、別の小さなゲームで動かすサンプルです。 左が自陣、右が敵陣です。

使徒の案内

ようこそ、新米神様

神様、この小さな世界では GitHub にあるソースが「法律の本」です。 main.js はHPや攻撃の届く距離を決め、style.css は見た目を決めています。

Character Passport JSON は、GodSandboxから別世界へ渡すキャラクター紹介状です。 この世界は紹介状から名前や姿を読み、戦い方はこの世界の法律で決めます。

まずは攻撃力を1上げて、「この法則で世界を作り直す」を押してみましょう。

読み込み中

sample-passport.json を読み込んでいます。

スマホでは GodSandbox の「キャラ情報をコピー」から、下の欄へそのまま貼り付けると簡単です。 名前や画像、紹介文、タグを読み込みます。

または、JSONファイルを選んで読み込めます。

GodSandboxからコピーして貼り付けるか、保存したキャラ情報JSONを選べます。何も読み込まなくても、このサンプルのRyoで遊べます。

          このサンプルの考え方

          Character Passport は、キャラクターを別のゲームへ連れて行くための紹介カードです。 このサンプルでは、名前、画像、紹介文、タグだけを読み、HPや攻撃力はこのゲーム側で仮に決めています。
